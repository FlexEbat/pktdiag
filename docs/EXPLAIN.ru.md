# Справочник Explain Engine

🇬🇧 [English version](EXPLAIN.md)

`pktdiag explain <термин>` (или `--explain` у `analyze` и `diagnose`)
ищет один из этих терминов. Алиасы указаны в скобках.

| Термин | Что покрывает |
|---|---|
| `retransmission` (`tcp.retransmission`) | TCP-сегменты, отправленные повторно из-за отсутствия ACK вовремя |
| `duplicate_ack` | Получатель подтверждает один и тот же байт дважды, обычно из-за пропущенного сегмента |
| `out_of_order` | Пакеты приходят не в порядке отправки |
| `zero_window` | Буфер получателя переполнен, отправителю велено приостановиться |
| `rst` (`tcp.reset`) | Соединение сброшено вместо штатного закрытия через FIN |
| `rtt` | Время кругового пути и что обычно означает его резкий рост |
| `dns_timeout` | DNS-запрос отправлен, ответ не получен |
| `dns_slow` | DNS-ответ пришёл медленно |
| `syn_flood` | Большой объём SYN без ответа, признак DoS или недоступного сервиса |
| `fragmentation` | IP-пакеты дробятся, так как превышают MTU по пути |
| `packets_dropped` | Ядро отбросило пакеты во время захвата, буфер или диск не успевают |
| `bandwidth` (`throughput`) | Средняя скорость передачи данных за время захвата |
| `pps` (`packets per second`) | Среднее количество пакетов в секунду за время захвата |
| `icmp_errors` (`icmp.errors`) | ICMP-сообщения об ошибке, не обычный ping-трафик |
| `mtu_mismatch` (`mtu.mismatch`) | Активные интерфейсы одного хоста сообщают разный MTU |

Каждая статья содержит пороги норма, warning, critical, описание простым
языком, типичные причины и рекомендации. Источник лежит в
[`internal/explainx/data/explain.json`](../internal/explainx/data/explain.json).
Чтобы добавить термин, добавьте новый JSON-объект в этот файл.
